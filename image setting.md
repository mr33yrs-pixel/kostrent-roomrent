# Image Setting Recommendations

Here are the recommended image sizes, aspect ratios, and resolutions for the Room Rental Application to ensure optimal performance, visual quality, and UI consistency across the admin panel and the public visitor site.

## 1. Application Logo
*   **Dimensions:** 512x512 pixels (Square) or 512x256 pixels (Landscape)
*   **Format:** PNG (with transparent background) or SVG
*   **Max File Size:** < 500 KB
*   **Usage:** Used in the admin panel sidebar, login page, and website header.

## 2. Favicon
*   **Dimensions:** 48x48, 96x96, or 144x144 pixels (Square)
*   **Format:** ICO or PNG (with transparent background)
*   **Max File Size:** < 50 KB
*   **Usage:** Displayed in the browser tab.

## 3. Room Images / Gallery
*   **Dimensions:** 1200x800 pixels (Aspect Ratio 3:2)
*   **Format:** WebP or optimized JPEG
*   **Max File Size:** < 1 MB per image (ideally < 300 KB)
*   **Usage:** Room details page and thumbnail listings. Consistency in aspect ratio is crucial to prevent UI layout shifts.

## 4. Homepage Hero Images / Banners
*   **Dimensions:** 1920x1080 pixels (Aspect Ratio 16:9)
*   **Format:** WebP or optimized JPEG
*   **Max File Size:** < 1.5 MB
*   **Usage:** Large background images on the main landing page and featured sections.

## 5. User Avatars
*   **Dimensions:** 256x256 pixels (Square)
*   **Format:** WebP, PNG, or JPEG
*   **Max File Size:** < 200 KB
*   **Usage:** User profiles in the admin panel.

## General Best Practices
*   **Compression:** Always compress images before uploading (using tools like TinyPNG or ImageOptim) if the application does not have an automatic image optimizer configured.
*   **Format:** Prefer **WebP** for photographs as it provides superior compression without noticeable loss in quality compared to JPEG. Use **PNG** or **SVG** for logos and graphics requiring transparency.
*   **Filenames:** Use lowercase, hyphen-separated filenames (e.g., `deluxe-room-balcony.jpg`) for better SEO and file system compatibility.
